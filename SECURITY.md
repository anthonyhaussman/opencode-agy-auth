# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `opencode-agy-auth`, please do not open a public issue.
Instead, report security concerns responsibly:

1. Use GitHub Private Vulnerability Reporting on this repository.
2. Provide detailed steps to reproduce the issue, including environment details and impact assessment.

We take security seriously and will review and respond to reports promptly.
